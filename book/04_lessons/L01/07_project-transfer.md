## 1. Why this page matters

This lesson introduced a lot of vocabulary and no hands-on work yet. Before moving on to [L02 – Data acquisition](../02_data-acquisition.md), it is worth spending a few minutes turning that vocabulary into an early, tentative direction for your own project — not a final decision, but a starting point you can revise as you learn more.

---

## 2. Project checklist

Apply this checklist to your own project idea.

- [ ] I can describe my project idea in one or two sentences, including a spatial dimension.
- [ ] I can name at least one application area from the [applications page](03_applications-of-geoai.md) that my idea relates to.
- [ ] I have a first guess at which [core GeoAI task family](05_core-geoai-tasks.md) fits my idea best.
- [ ] I can name at least one property from the [spatial data page](02_why-spatial-data-is-different.md) that will matter for my project.
- [ ] I know which parts of the [Python ecosystem](04_python-ecosystem.md) I am already comfortable with, and which are new to me.

---

## 3. Reflection questions

Answer these briefly for your own project:

1. What real-world phenomenon or question do I want to study?
2. Which application area from this lesson is closest to my idea?
3. Does my idea sound more like detection, segmentation, change, translation, or regression?
4. What resolution or scale would I need to actually observe the pattern I am interested in?
5. What is one thing about GeoAI that still feels unclear to me after this lesson?

```{tip}
It is completely fine if your answer to a question changes after the next few lessons. The point of this page is to have a starting point to revise, not a locked-in plan.
```

---

## 4. Mini deliverable

Write a short **project framing note** — three to five sentences — that you can return to and revise as you progress through the book.

Use this structure:

```text
Project idea (one or two sentences):
Application area:
Likely task family:
Data I expect to need (raster, vector, or both):
One open question I still have:
```

Save it somewhere you will find again, for example:

```text
notes/project_framing.md
```

---

## 5. Key takeaways

* An early project direction does not need to be final — it needs to be specific enough to act on.
* Naming an application area and a likely task family now will make the next lessons easier to follow with your own project in mind.
* The next lesson, [L02 – Data acquisition](../02_data-acquisition.md), is where you start testing whether the data your idea needs actually exists and is accessible.
